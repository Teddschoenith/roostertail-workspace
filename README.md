# Roostertail Rep Workspace

Your working folder for proposals, research, and event work with the Roostertail assistant.

## One-time setup (about 5 minutes)

1. Install the ChatGPT desktop app and sign in with your @roostertail.com account.
2. Open Terminal (press Cmd+Space, type "Terminal", press Return) and paste this, then press Return:

```
git clone https://github.com/Teddschoenith/roostertail-workspace.git ~/Roostertail
```

3. In ChatGPT desktop: Settings, General, set the task folder to the new `Roostertail` folder in your home folder (or open it as a project).
4. In a new chat, attach the RCMS app and sign in with YOUR RCMS login. You will get a text message code. This is one time; it remembers you.
5. Try it: "Build a proposal for the Johnson wedding." Answer its questions. That's the whole job.

## What's in here

- `AGENTS.md` — the assistant's standing orders. You can edit them; it obeys this file.
- `packages/` — the current wedding and special events packets (reference copies; live pricing comes from RCMS).
- `proposals/` — finished proposals, filed by year and client.
- `research/` — client and company research notes.
- `inbox/` — drop anything here; the assistant files it for you.

## House rules baked in

The assistant always works from RCMS (never guesses pricing), interviews you before drafting a proposal, shows you the copy and the math once, and builds the file after you say go.
